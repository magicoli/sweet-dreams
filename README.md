# Sweet Dreams

Tablet-based alternative for the legendary Sony Dream Machine ICF-CL70 2009.

## Goals

- large hour display
- customizable alarm sound
- customizable background
- adaptative day/night theme
- modular (weather, calendar, motd, ...)
- AI integration
